MERGE WATCHER - Power Automate Desktop flow, built by hand (10 actions)
======================================================================
Start it ONCE a day from the Power Automate Desktop console (Run). A console
start never asks "Continue". It keeps running and merges every case:

  After each case's narratives the tool writes one small file per entity to
     Downloads\ECM_Imported\MergeRequests\   e.g. 149305_CP1.txt
  Each file has 3 lines:
     line 1  the case's OSDD Searches folder
     line 2  which PDFs belong to the entity       e.g. *_CP1_*.pdf
     line 3  the merged PDF to create (same name as your PDF Merge makes)
  Every 5 seconds the flow merges each request and deletes it.

If the flow isn't running the requests simply wait - start it and it catches up.
Stop it with Stop in the console when you need the manual PDF Merge button
(Power Automate runs one flow at a time). The tool creates the MergeRequests
folder when it opens, so open the tool once before the first run.


BUILD IT  (Power Automate Desktop > + New flow > name: Merge Watcher)
--------
Search each action by name in the Actions pane (left) and drag it in.
Text in %...% is typed exactly as shown (the % signs included).

 1. "Get Windows environment variable"
        Environment variable name:  USERPROFILE
        (produces variable  EnvironmentVariableValue)

 2. "Loop condition"
        First operand:   1
        Operator:        Equal to (=)
        Second operand:  1
    -> actions 3 to 10 go INSIDE this loop (between Loop condition and its End)

 3. "Get files in folder"
        Folder:       %EnvironmentVariableValue%\Downloads\ECM_Imported\MergeRequests
        File filter:  *.txt
        (produces variable  Files)
        Rename the produced variable to  Requests  (click the variable name under
        "Variables produced" and type Requests)

 4. "For each"
        Value to iterate:  %Requests%
        Store into:        CurrentItem
    -> actions 5 to 8 go INSIDE this For each

 5. "Read text from file"
        File path:                %CurrentItem%
        Store content as:         List (each line is a list item)
        Encoding:                 UTF-8
        (produces variable  FileContents)

 6. "Get files in folder"
        Folder:       %FileContents[0]%
        File filter:  %FileContents[1]%
        Advanced > Sort by: Name, Descending: ON
        (produces variable  Files)

 7. "If"
        First operand:   %Files.Count%
        Operator:        Greater than (>)
        Second operand:  0
    -> inside this If, add:
        "Merge PDF files"
            PDF files:         %Files%
            Merged PDF path:   %FileContents[2]%
            If file exists:    Overwrite

 8. "Delete file(s)"   (after the If's End, still inside the For each)
        File(s) to delete:  %CurrentItem%

 9. (nothing - this is where the For each ends)

10. "Wait"   (after the For each's End, still inside the Loop condition)
        Duration:  5   (seconds)

RECOMMENDED: in "Merge PDF files" and "Delete file(s)" open "On error" (bottom
left of the action) > Continue flow run > Go to next action. Then a locked or
open file skips that one request instead of stopping the watcher.

Save, then Run. Leave it running.

Finished flow should read:
   Get Windows environment variable
   Loop condition 1 = 1
       Get files in folder  -> Requests
       For each CurrentItem in Requests
           Read text from file  -> FileContents
           Get files in folder  -> Files
           If Files.Count > 0
               Merge PDF files -> FileContents[2]
           End
           Delete file(s) CurrentItem
       End
       Wait 5
   End

TEST: with the flow running, copy any case's request by hand - create
Downloads\ECM_Imported\MergeRequests\test_CP1.txt in Notepad with 3 lines
(OSDD folder, *_CP1_*.pdf, a merged path) - it should disappear within ~5 s and
the merged PDF appear.


IF PASTING WORKS ON SOME MACHINE (optional, same flow as text)
-----
System.GetEnvironmentVariable.GetEnvironmentVariable Name: $'''USERPROFILE''' Value=> EnvironmentVariableValue
LOOP WHILE (1) = (1)
    Folder.GetFiles Folder: $'''%EnvironmentVariableValue%\\Downloads\\ECM_Imported\\MergeRequests''' FileFilter: $'''*.txt''' IncludeSubfolders: False FailOnAccessDenied: False SortBy1: Folder.SortBy.CreationTime SortDescending1: False SortBy2: Folder.SortBy.NoSort SortDescending2: False SortBy3: Folder.SortBy.NoSort SortDescending3: False Files=> Requests
    LOOP FOREACH CurrentItem IN Requests
        File.ReadTextFromFile.ReadTextAsList File: CurrentItem Encoding: File.TextFileEncoding.UTF8 Contents=> FileContents
        Folder.GetFiles Folder: FileContents[0] FileFilter: FileContents[1] IncludeSubfolders: False FailOnAccessDenied: False SortBy1: Folder.SortBy.Name SortDescending1: True SortBy2: Folder.SortBy.NoSort SortDescending2: False SortBy3: Folder.SortBy.NoSort SortDescending3: False Files=> Files
        IF Files.Count > 0 THEN
            Pdf.MergeFiles PDFFiles: Files MergedPDFPath: FileContents[2] IfFileExists: Pdf.IfFileExists.Overwrite PasswordDelimiter: $''',''' MergedPDF=> MergedPDF
        END
        File.Delete Files: CurrentItem
    END
    WAIT 5
END
-----
Pasting tips: copy from Notepad (not a web page), click once on the empty
flow area, then Ctrl+V or right-click > Paste.
